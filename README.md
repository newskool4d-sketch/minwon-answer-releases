# 민원답변 도우미

Windows용 민원답변 도우미의 **배포 파일·한국어 안내서·자동 업데이트 전용 저장소**입니다. 소스 저장소는 비공개로 유지합니다.

[최신 릴리스](https://github.com/newskool4d-sketch/minwon-answer-releases/releases/latest) · [v0.11.0 설치 파일 내려받기](https://github.com/newskool4d-sketch/minwon-answer-releases/releases/download/v0.11.0/minwon-answer-0.11.0-setup.exe) · [한국어 안내서](https://github.com/newskool4d-sketch/minwon-answer-releases/releases/download/v0.11.0/minwon-answer-0.11.0-guide-ko.html)

v0.8.0은 사용자당 기관 프로필 하나, 파일 공유, 소속·성명·연락처 기본 안내, 성명 생략 경고와 확정 안내 보존을 제공합니다. 지역·기관 값은 사용자가 입력합니다.

v0.9.0은 머리말·맺음말·만족도 조사 안내를 기관 프로필에서 직접 설정하고 공유하며 확정 당시 문구를 보존합니다. 지역·기관별 값은 하드코딩하지 않습니다.

v0.10.0은 내부 보고용 민원 요약을 대민 답변과 별도 탭으로 제공하며, 로컬 발췌·수정·저장·복사·다운로드를 지원합니다. 추가 AI 전송이나 지역 맥락 하드코딩 없이 사용합니다.

v0.10.1은 Claude 공식 로그인 창·수동 주소 안내·기관망 프록시/CA 환경 전달을 보완했습니다. 기존 구독 로그인은 유지합니다. 실제 기관망 PC 검증은 사용자 별도 진행 예정입니다.

v0.11.0은 AI 연결 설정에서 버튼 하나로 공식 Claude Code·Codex 설치와 브라우저 로그인을 진행하고, 창이 닫히면 연결 상태를 자동으로 확인합니다. 처음 설치는 설치 마법사(`-setup.exe`)를 사용하며 [설정 > 앱]에서 제거할 수 있습니다. 기관 PC에서 연결을 확인했습니다.

## 기존 사용자는 한 번 직접 업데이트하세요

**v0.6.0 이하 사용자는 최신 설치 파일(v0.11.0)을 한 번 직접 내려받아 실행해야 합니다.** v0.5.3 이하에는 자동 업데이트 기능이 없고, v0.6.0의 업데이트 주소는 일반 사용자에게 열려 있지 않습니다. v0.6.1 이상 사용자는 자동 업데이트로 받을 수 있습니다.

1. 기존 앱에서 **작업 내보내기**로 작업을 보관하고 앱을 닫습니다.
2. 최신 설치 파일(`minwon-answer-<버전>-setup.exe`)을 내려받아 실행하고 필요하면 **작업 불러오기**로 JSON을 엽니다.
3. **저장 설정**에서 작업 폴더와 자동 저장을 지정합니다. 작업 저장 기본값은 꺼짐입니다.
4. **업데이트**의 자동 업데이트를 켜 두면 이후 정식 새 버전을 확인·다운로드하고 정상 종료 뒤 적용합니다. 기본값은 켜짐입니다.

## 사용 환경과 파일 확인

- Windows 10·11 x64. 앱 실행에 Node.js를 별도로 설치할 필요가 없습니다.
- Codex·Claude는 앱의 **AI 연결 설정**에서 **설치하고 연결**로 공식 프로그램 설치와 본인 로그인을 진행합니다(Claude는 Pro 이상 구독 필요). Gemini는 본인 API Key를 준비합니다. 자세한 방법은 릴리스의 한국어 안내서를 참고하세요.
- 처음 설치는 `-setup.exe`를 사용하세요. 같은 릴리스의 `-win-x64.exe`는 이전 버전의 자동 업데이트가 쓰는 파일입니다.
- 내려받은 파일은 같은 릴리스의 `.sha256`과 대조하세요. 현재 실행 파일에는 코드 서명이 없으므로 기관 실행 정책을 따르세요.
- 제거는 [설정 > 앱 > 민원답변 도우미]에서 합니다. 작업 파일·설정·로그인 정보는 남습니다.
- 프로그램은 로컬 PC에서 실행하며, 실제 민원·내부 자료의 외부 AI 전송은 차단합니다. 가상 예시로 먼저 확인하세요.
- 작업·설정·로그인 폴더는 업데이트 시 유지하며, API 키·로그인 토큰·전송 동의를 작업 파일에 저장하지 않습니다.
- v0.7.0의 작업 파일(형식 2)은 v0.6.1 이하에서 열 수 없습니다. 이전 버전으로 되돌리기 전에는 **작업 내보내기**로 보관하세요.

이 저장소의 Git 파일은 배포 안내만 포함합니다. 실행 파일과 안내서는 **Releases**에서 내려받으세요.
